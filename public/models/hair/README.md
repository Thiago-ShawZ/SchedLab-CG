# Modelos 3D de Cabelo e Manequim (/models/hair/)

Este diretório aceita modelos GLB para a visualização 3D de tipos de cabelo:

1. `head-base.glb`: Busto/cabeça do manequim base (opcional).
2. `hair-{id}.glb`: Modelos específicos de cabelo para cada tipo:
   - `hair-liso.glb`
   - `hair-ondulado.glb`
   - `hair-cacheado.glb`
   - `hair-crespo.glb`
   - `hair-seco.glb`
   - `hair-oleoso.glb`

Se os arquivos `.glb` não estiverem presentes, o sistema utiliza automaticamente a renderização procedural estilizada correspondente.
